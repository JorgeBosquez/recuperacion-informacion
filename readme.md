# Recuperación de Información: TF-IDF y BM25

## Descripción
Este proyecto contiene la implementación de dos modelos de recuperación de información:

- TF-IDF (Modelo Vectorial)
- BM25 (Modelo Probabilístico)

## Contenido
- 03tfidf.ipynb → implementación TF-IDF
- 04bm25.ipynb → implementación BM25
- data/
  - 01_corpus_turismo_500.txt
  - corpus_limpio.zip

## Dataset
Se utiliza un corpus de libros de Project Gutenberg previamente limpiado.
