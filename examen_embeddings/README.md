# Sistema de Recuperación de Información con Embeddings

## Descripción

Este proyecto implementa un sistema de recuperación de información utilizando embeddings semánticos con Sentence Transformers y similitud coseno sobre el dataset Rotten Tomatoes.

## Requisitos

Instalar dependencias:

```bash
pip install -r requirements.txt
```

## Dataset

Colocar los archivos:

- rotten_tomatoes_movies.csv
- rotten_tomatoes_critic_reviews.csv

dentro de la carpeta:

```text
archive/
```

## Ejecución

Abrir el notebook:

```text
BosquezJorge_ex1bim_ir26a.ipynb
```

y ejecutar:

```text
Restart Kernel → Run All
```

## Funcionalidades

- Preprocesamiento textual
- Generación de embeddings
- Recuperación semántica
- Similitud coseno
- Benchmark de consultas
- Visualización PCA
